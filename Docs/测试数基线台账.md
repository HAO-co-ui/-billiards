# 测试数基线台账

> **目的**：防止「过期数字被当作有效数字」。
> 起因（2026-10-13）：`58`、`66`、`72` 三个数字都曾被称为"全绿"，
> 但它们**对应三个不同的修订** —— 不标修订地引用，复核方会把过期数字当有效。

---

## 规矩（强制）

**报测试数时必须带修订**，格式：

```
<通过数>/<总数> @ <提交短哈希 或 "工作区">
```

例：`72/72 @ 工作区（切片 A 后，未提交）` —— **不得只写「72/72 全绿」**。

适用对象：EditMode / PlayMode 测试数、三个验收器（Day1/2/3）的通过数、
以及任何"我跑了、通过了"的计数型断言。
