### 0.2 为什么必须先出 spec

内核 I 的验收里，**「反射角 < 1°」单独使用没有判别力**（`e` 被写死成 1 时角度照样守恒）。
球-球这一轮有**完全同族**的坑，而且更隐蔽：

| 排期给的检查项 | 能测出 | **测不出** |
| --- | --- | --- |
| 对心碰撞速度交换 | 未解算球-球接触、法向错 | `e_ball` 被写死成 1（交换本来就只对 e=1 成立） |
| 斜碰约 90° 分离角 | 法向错、分量分解错、**μ 污染法向** | **`e_ball` 的任何错误**（90° 只在 e=1 成立） |
| 动量守恒 | 冲量不对称、单边解算 | `e_ball` 取错（任何 e 都守恒）；**能量耗散量** |
| —（排期未列） | — | **穿透**：球-球若不做 TOI，高速对开会互相穿过 |

⇒ **四项必须成套**，另补**穿透**一项。本 spec §5 的测试族即为补齐这五列而设计；
其中「90° = 90°」这条**不得**被当作 `e_ball` 的检出保证（理由见 §2.4，含推导）。

### 0.3 本轮最重的一条：**事件循环的作用域必须从"单球"改成"全局"**

内核 I 的 `Step()` 是 **逐球独立积分**：

```
Step() → for sub in SubSteps → for i in balls → IntegrateBall(i)     // 每球走完整的子步
```

`EarliestToi` 只遍历**段**，`ResolveContact` 只解算**段接触** ⇒ **球与球之间完全没有相互作用，
会直接互相穿过**。而球-球接触在几何上是**一对球的共同事件**，无法在"逐球独立"的框架里表达。

⇒ **必须把子步内的事件循环提升为"全局最早事件"**（§2.2）。这是本轮的**架构变更**，
也是最大的一处风险来源（§9 `R-L`）：它**改变了 `MaxToiIterations` 的语义**
（"每球每子步"→"每子步全局"），因此内核 I 那句"预算 128 ⇒ guardTrips=0"的实测依据**不再直接适用**，必须重验。

## 1. 既定事实（读当前代码 + 解析计算，非推断）

### 1.1 当前内核**没有**球-球建模（逐行确认）

| 位置 | 现状 | 后果 |
| --- | --- | --- |
| `PoolSimulator.Step` | `for sub → for i(_balls.Length) → IntegrateBall(i)` | 每球独立走完整个子步 |
| `PoolSimulator.IntegrateBall` | 只调 `EarliestToi`（段）与 `ResolveContact`（段组） | 球之间无任何耦合 |
| `EarliestToi` | `for i in _segA.Length` | **只找段**，不找球 |
| `ResolveContact` | `for g in group`（段索引） | 只解算段接触 |

⇒ **两球相向运动会互相穿过**，且不会有任何计数器报警（静默）。这是本轮要修的核心缺口。

### 2.1 单一口径参数表（唯一真源，实现不得自行造值）

| `ballInitialOverlapTolerance` | **`PoolSimulator`** 常量 | 合法初始摆放的两球间距下限：`|Δp| ≥ 2r − 该值` | **1e-4 m** | ❌ 否（**校验期**常量，不参与积分） |

| 球-球位置修正系数 | **`PoolSimulator`** 常量 | 重叠分离时两侧**各推一半** | 0.5 / 0.5 | ✅ 是 |

> **⚠「运行时默认 0.95」≠「只测 0.95」**：**默认值**是玩法侧的开箱取值；
> **单测必须两档都跑** —— `1.0` 档给"严格 90°"这类**可判定到浮点量级**的判据，
> `0.95` 档给**真实感**与"e 的检出"（`T16b`/`T17`）。两者不可互相替代。

**口径一致性要求**（与内核 I 同源）：
- `e_ball` 与 `μ_ball` **各自独立作用于各自分量**，**不得**合并为"先反射再统一缩放"
  （那会把 `μ_ball` 乘到法向分量上 —— 内核 I 已记录该陷阱）。
- `e_ball` **不得**与库边的 `cushionRestitution` 共用一个字段：两者是**不同接触对**的物理量，
  库边是"球 vs 静态墙"，球-球是"球 vs 等质量球"。合并会让"只改库边手感"污染球-球行为。

### 2.2 架构：子步内**全局最早事件**循环（本轮唯一架构变更）

**现状（内核 I）**：`Step → for sub → for i → IntegrateBall(i)` —— 每球走完整个子步。

**本轮**：把"子步内"提升为**全局事件循环**：

```
子步推进(Δ):
    remaining = Δ
    iterations = 0
    while remaining > ToiRemainingEpsilon:
        if ++iterations > MaxToiIterations: 守卫计数++; break

        # 1) 全局最早事件：段接触 与 球-球接触 一起搜
        earliest = +inf; 事件 = 空
        for i in 球索引升序:                     # ← 保留升序球遍历（D-3 依赖）
            for j in 段索引升序:
                t = SolveToi(p_i, vAvg_i, seg_j, r)
                若 t ∈ [0, remaining] 且是"进入"接触 → 候选(i, j)
        for i in 球索引升序:
            for k in (i+1)..n 升序:
                t = SolveBallBallToi(p_i, vAvg_i, p_k, vAvg_k, r)
                若 t ∈ [0, remaining] → 候选对 (i, k)

        # 2) 若无事件：全部活跃球自由飞行到子步末，结束
        if 无候选:
            for i 升序: p_i += vAvg_i * remaining
            break

        # 3) 归并同刻事件（|t − earliest| ≤ ToiTimeEpsilon），**全部活跃球**推进到 earliest
        for i 升序: p_i += vAvg_i * earliest
        remaining -= earliest

        # 4) 解算该时刻的接触组（段组按段索引升序；球-球对按 (i,k) 升序）
        解算接触()

        # 5) 近零速度 / 连续两次零时间推进 两个即停判据（沿用内核 I，扩展到全局）
        ...

        # 6) 按新速度重取各球 vAvg（若 a > 0）
```

**为什么必须"推进所有球"而不是只推进参与事件的球**：`earliest` 是**全局**最早接触时刻；
其余球在 `[0, earliest)` 内无事件，必须同样前进，否则时间轴在球之间错位。

**备选方案与为何不选**：

| 备选 | 描述 | 为何不选 |
| --- | --- | --- |
| **B. 保留逐球循环，球-球只在子步末做一次采样重叠解算** | 改动最小 | ① 重叠可达 **44 mm**（§1.3），与 ≤1e-5 m 的标准差 4 个数量级；② 解算顺序依赖"哪只球先被访问"，**确定性脆弱**；③ 高速对开在子步内已穿越，**无法事后修复** |
| **C. 只对球-球做 TOI，段接触仍逐球** | 折中 | 两条时间轴（球的段事件 vs 球对事件）无法归并 ⇒ **同刻多接触**（球同时撞段与撞球）会漏解算，直接放大内核 I 的 `R-C`（角点升能） |
| **D. 用固定小步长（把 `SubSteps` 提到 300+）代替 TOI** | 简单 | 内核 I 已实测：把自由飞行误差压到 1e-5 m 需 `SubSteps ≥ 3333`；且**改变既有验收数量级**，等于推翻内核 I 的结论 |

⇒ **采用全局事件循环**。它与排期第 3 条"O(n²) 足够，接口留好"不冲突（宽相位见 §2.7）。

### 2.3 球-球 TOI 的解析解（第一性原理）

两球（半径同为 `r`）在子步内以**常均速** `v_i`、`v_k` 运动。设相对量：

```
d  = p_i − p_k        (相对位置)
w  = v_i − v_k        (相对速度)
接触条件： |d + w·t|² = (2r)²
展开：     |w|²·t² + 2(d·w)·t + (|d|² − 4r²) = 0
```

```
A = |w|²,  B = 2(d·w),  C = |d|² − 4r²
若 A ≤ 0            → 无相对运动 ⇒ 无接触（返回 +∞）
disc = B² − 4AC < 0 → 无实根 ⇒ 无接触
t = (−B − √disc) / (2A)          # 较早根 = "进入"时刻
```

**接受条件**（三条全满足才接受）：
1. `t ∈ [0, remaining]`（本子步内、未过期）；
2. **接近**：`d·w < 0`（两者在靠近）。等价地：接触点相对法向速度 `< 0`。
   这一条与内核 I `RayCircleToi` 的"仅接受进入"同构 —— **否则已分离的球会在 t=0 反复自触发**；
3. 反向校验：用 `normalize(d + w·t)` 复核接触法向与相对速度相反（浮点保护）。

**与段 TOI 的关系**：两者**共用** `ToiTimeEpsilon` 归并窗口，进入**同一个** `earliest` 竞争。
⇒ 球同时撞库边与撞球（三体同刻）会被归并成一组统一解算 —— 这正是内核 I `R-C` 家族的放大场景（§9 `R-M`）。

### 2.4 「斜碰 90°」的真伪与它的**判别力边界**（本节独立推导，不复述实现）

等质量 `m`、球 k 静止、接触法向沿 x。设球 i 入射 `(vx, vy)`、恢复系数 `e`：

```
v_i′ = ( vx(1−e)/2 ,  vy )          v_k′ = ( vx(1+e)/2 ,  0 )
```

**分离角**（`v_k′` 恒沿 +x，故夹角 = `v_i′` 的极角）：

```
θ(e) = atan2( vy , vx(1−e)/2 )        ← 甲类闭式解（本 spec §5 T16 的期望值来源）
v_i′·v_k′ = vx²(1−e²)/4   ⇒   θ = 90°  ⟺  e = 1
```

> **⚠ `vx` / `vy` 的语义（必须在实现与测试里写死）**：
> **`vx` = 入射速度在接触法向 `n̂` 上的分量，`vy` = 在切向 `t̂` 上的分量**；
> 上式里的 `θ` 是 **`v_i′` 相对 `n̂` 的角度**（`v_k′` 恒沿 `n̂`，故夹角即此）。
> 混用法向/切向会得到错误期望值 —— 本 spec 的 `T16` 曾因几何写错踩过一次，故此处显式声明。

| e | `v_i′` | θ（`vx = vy = v`） |
| --- | --- | --- |
| **1.00** | `(0, v)` | **90.000°**（严格） |
| **0.95** | `(0.025v, v)` | **88.567°** |

⇒ **两条硬结论**：
1. **「约 90°」不是普适常数，它依赖 e。** 容差按 ±0.5° 写会对 e=0.95 档**假失败**；按 ±2° 写等于没验。
   ⇒ 故用户已拍板"两档都做"：`e=1` 档给**严格判据**，`e=0.95` 档给**甲类解析判据**。
2. **⚠ 原表述"判别力随 e 偏离 1 而单调下降"是错的**（主理人已认领该错误；`dθ/de` 在 `e=1` 处**不是 0**）。
   正确事实（`vx = vy = v` ⇒ `θ = atan(2/(1−e))`）：

```
dθ/de = 2 / ((1−e)² + 4)   rad / 单位 e
   e = 1.00 ⇒ 0.500000 rad = 28.6479 °/单位 e     ← 不是 0
   e = 0.95 ⇒ 0.499688 rad = 28.6300 °/单位 e
0.01° 容差 ⇒ e 被钉在 1 ± 3.49e-4   ⇒ 是"紧"，不是"盲"
```

   - **`T16a` 档（`e_ball` 配成 1.0）的局限不是盲带，而是"对 e 不具信息"**：
     **1.0 同时是"忽略 e"与"正确应用 e=1"的解** ⇒ 该档**分不出这两者**；
   - **`T16b` 档（配 0.95）才是 e 真实性的承担者**：忽略 e ⇒ θ = 90°，偏 **1.43° ≫ 0.05°** ⇒ FAIL ✓；
   - ⇒ **不得放宽 `T16a` 的容差** —— 它反而是**最紧的 e 约束**。

   对 e **更直接**的判据仍是**沿法向的相对速度**与**动能耗散量**：

```
法向相对速度：  v_rel,n′ = e · v_rel,n        （e 从 1→0.95 时该量单调变化 5%）
动能耗散（等质量）：ΔKE = −(1−e²)·m·(v_rel,n)²/4
e=0.95, v_rel,n = v ⇒ ΔKE/KE = −(1−e²)/2 = −4.875%
```

⇒ **本 spec 把"`e_ball` 是否正确"交给 T17（动能耗散量，甲类闭式）**，而不是交给角度。
**这是"不要把有盲带的检查当检出保证"的直接应用**（§5 每条判据都要求声明盲带）。

### 2.5 `μ_ball` 在本轮为什么必须钉死为 1（请在评审里重点挑战）

排期第 1 条写了"**切向摩擦传递**"。但本轮**没有自旋建模**（自旋/塞明确属后续轮次）。

**⚠ 原理由已被独立复核推翻，此处按复核结论改写（结论不变，理由换掉）**：
原写"无自旋 ⇒ 接触点切向相对速度**恒为零** ⇒ 无耗散通道" —— **该前提为假**。
独立推导（`n̂ = x̂`、`v_i = (1,−1)`，球 k 静止）：

```
v_rel,t = (v_i − v_k) − [(v_i − v_k)·n̂] n̂ = (0, −1) ≠ 0
```

⇒ **无自旋时接触点的切向相对速度通常非零。** 正确的理由是：

- 切向相对速度**确实存在**，它的**物理汇是自旋**（球开始旋转）—— 而本模型**没有角自由度**；
- 因此按 `μ_ball < 1` 去衰减 `v_rel,t` 属**非物理耗散**（动能被凭空拿走，无处可去）；
- ⇒ **光滑球（`μ_ball = 1`，切向分量不变）是无自旋模型下唯一自洽的选择**。
- 且 **90° 判据本身就要求 `μ_ball = 1`**：`μ_ball < 1` 会把 `v_i′` 的切向分量额外缩短，
  使"90°"这一条**同时依赖两个参数**，判据不再干净。

⇒ **本轮 `μ_ball = 1`（无切向损耗）**，参数**保留在结构里**并在注释里写明
"允许 ≠1 的条件是引入自旋之后"。排期的"切向摩擦传递"因此**降级为本轮不实现**，
并在 §8 明确非目标 + §7 ⑦ 项请用户确认。

### 2.6 接触判定与分离（防抖动、防粘滞）—— 排期第 2 条

| 机制 | 规则 | 为什么需要 |
| --- | --- | --- |
| **位置修正** | 解算后若两球仍重叠（`|Δp| < 2r`），沿 `n̂` **各推一半**，使间距 = `2r` | 不修正 ⇒ 下一迭代立刻再触发同一对接触（抖动/粘滞） |
| **近零速度即停** | 沿用 `StoppedSpeedEpsilon`（扩展到全局循环） | 接触解算按 `e^{2k}` 几何衰减，**永不精确为 0**（内核 I 实测） |
| **连续两次零时间推进即停** | 沿用内核 I 的第二半修复 | 球楔死在凹角/夹在两球之间时，`earliest = 0` 且 `remaining` 不减 ⇒ 空转 |
| **初始重叠（合法边界）** | **不在运行时夹断**；由校验期拒绝 `|Δp| < 2r − 1e-4 m` 的初始摆放 | 与库边的"贴库静止球"同族：合法摆位可落在边界上，抛异常会把合法局面判死 |
| **深层重叠的确定处置** | 若子步**开始时**已 `|Δp| < 2r`（越过了校验期，例如被位置修正推入），TOI 无未来根 ⇒ **立即按 `n̂ = normalize(Δp)` 解算一次接触并做位置修正**，计一次接触 | **不得静默**：否则两球会带着重叠继续各自飞（相当于静默穿透） |
| **单一对只解一次** | 同一次事件里，同一个球对**只解算一次**（即使被多次判为同刻） | 防止双倍冲量 |
| **球-段的"接近"判据（`R12`，球-球有、球-段原缺）** | 与球-球同构：**仅接受"进入"根**（要求 `sv·s0 < 0`）⇒ **内侧正在分离的球不会被多余反射**；**必须与球-球共用同一判据形态** | 不加 ⇒ 已分离的球被反复反射（假接触、能量异常） |
| **合法贴库静止球（`R12`）** | 贴库静止球因 float 落在 `r − ε` ⇒ 深层重叠处置**会每子步触发** ⇒ 须**声明**：其位置微漂移与计数增长是**已知且可接受**的，**不得**被当作缺陷 | 不声明 ⇒ 计数污染被误判为 bug |
| **贴库球的浮点边界（球-段同族，`T24` 直接依赖）** | 球心距库段 **恰为 `r`** 时，`\|s0\|` 在 float 下可能是 `r ± ε`。**`\|s0\| ≥ r` 一侧**：正常"进入"根（`t` 可为 0）；**`\|s0\| < r` 一侧（已重叠）**：段 TOI **无"进入"根** ⇒ **必须与球-球共用同一套深层重叠处置**（立即解算一次 + 位置修正），否则球会**静默钻入库边** | `T24` 的"球 B 恰贴库"正落在这个边界上；两个方向都必须被确定处置，**不得只处理一侧** |

### 2.7 空间划分：O(n²) + **一个函数边界**（排期第 3 条）

本轮固定 **O(n²)**：16 球 ⇒ **120 对**，每子步 3 次 ⇒ 360 次配对求交，可忽略。

**"接口留好"的准确含义（本 spec 的收敛解释）**：
> 把"候选球对"的产生收敛到**一个函数**（如 `CollectCandidatePairs`），**本轮实现为双层升序循环**。
> 后续（AI 推演放大调用量时）可**只替换该函数体**为网格/扫描-剪枝，**调用方与顺序语义不变**。

**明确不做**：不引入 `IPairProvider` 接口/泛型/委托 —— 那是**为假想的第二实现付抽象成本**，
而当前只有一个实现，且替换点已被一个函数隔离。

**该函数必须被测试守住**（否则将来换网格法会**静默漏对** ⇒ 漏碰撞 ⇒ 穿透）：见 §5 **T25**
（小规模下产出 == 暴力枚举）。

## 4. 求解过程 spec

### 4.1 子步（见 §2.2 伪码）；**位置与 TOI 共用同一 `v_avg`**（内核 I 既有要求，本轮不变）

### 4.2 球-球接触解算（等质量）

对每个球对 `(i, k)`，**按 (i,k) 升序**：

```
d  = p_i − p_k
n̂  = normalize(d)                    # 由 k 指向 i
     ├─ 若 |d| < 1e-9 → 退化（球心重合）：取 -normalize(v_i − v_k) 为 n̂；仍为零则取 (1,0)
v_rel = v_i − v_k
v_n   = dot(v_rel, n̂)                 # n̂ 指向 i ⇒ v_n < 0 表示 i 正在靠近 k
若 v_n ≥ 0: 跳过（已在分离，不产生冲量）      # ★ 与"仅接受进入"同构

J = −(1 + e_ball) · v_n / 2           # 等质量 ⇒ 各承担一半冲量；m 归一化后即此式
v_i += J · n̂
v_k += −J · n̂

# 切向：μ_ball = 1 ⇒ 切向分量不变（无自旋模型下无切向冲量）
# 若将来 μ_ball < 1，必须在此处独立赋值切向分量，且不得污染 v_i/v_k 的法向分量
```

**等质量闭式校验**（供评审对照，不复用实现公式）：
> `v_i′ = v_i − J n̂`、`v_k′ = v_k + J n̂`，其中 `J = (1+e)(v_k − v_i)·n̂ / 2`。
> 代回即得 §2.4 的 `v_i′ = (vx(1−e)/2, vy)`、`v_k′ = (vx(1+e)/2, 0)`（k 静止、n̂ = x̂）。

**位置修正**（防抖动）：
```
overlap = 2r − |d|
若 overlap > 0:  p_i += (overlap/2)·n̂ ;  p_k −= (overlap/2)·n̂
```

### 4.3 不变量（沿用内核 I 的两组划分，本轮扩到球-球）

**组 ①：模型内自洽（必须精确成立）**

| 不变量 | 断言 |
| --- | --- |
| 球-球接触后间距 = 2r | `|dist(C_i, C_k) − 2r| ≤ 1e-6 m` |
| 球-球法向相对速度反向且衰减 | `v_rel·n̂` 符号翻转；`|v_rel′·n̂| ≤ e_ball·|v_rel·n̂| + 1e-6` |
| 球-球动量守恒（等质量） | `|v_i′ + v_k′ − (v_i + v_k)| ≤ 1e-6`（绝对，m 归一化） |
| 无升能（球-球） | `KE_out ≤ KE_in·(1 + 1e-6)`，计入 `EnergyGainViolations` |

**组 ②：模型 vs 真值（只能实测/解析，不得仅凭公式声称）**

| 量 | 甲类来源 |
| --- | --- |
| 分离角 | `θ(e) = atan2(vy, vx(1−e)/2)`（§2.4） |
| 动能耗散 | `ΔKE = −(1−e²)m(v_rel,n)²/4`（§2.4） |
| 对心交换 | `e=1` ⇒ 速度完全交换（一维弹性等质量） |

### T16 斜碰分离角（排期三项之二，**两档参数化**）

**发射状态**（**已修正**：原写 `A(-0.20, 0.40)`、`v = (1,−1)` —— `B−A = (0.4, −0.4)` 与 `v` **严格平行**
⇒ 碰撞参数 = 0 ⇒ 那是**对心碰撞而非斜碰**，且与括注"接触法向沿 x"自相矛盾）：
球 B 静止于 `(0.20, 0)`；球 A 自 **`(-0.20, 0.34285)`** 以方向 `(1, −1)` 入射，`μ_ball = 1`。

**几何推导（先写清几何，再谈期望值）**：

```
要求接触法向沿 x ⇒ 接触时两球心同 y ⇒ A 的 y 位移 = −y0
接触位置：A.x = B.x − 2r = 0.20 − 0.05715 = 0.14285 ⇒ A 的 x 位移 = 0.34285
速度方向 (1,−1) ⇒ Δy/Δx = −1 ⇒ y0 = 0.34285
碰撞参数 = 2r·sin45° = 0.05715 / √2 = 0.040411   ( ≠ 0 ✓ 确为斜碰 )
```

> **墓碑（曾有一条"镜像解"声明，已删除 —— 因已被复算证伪）**：
> 本 spec 曾写「另有镜像解 `y0 = 0.45715`，法向 `(−1,0)`，**两解均经独立复算**」。
> **该声明不成立**：`y0 = 0.45715` 时首次接触点在 `(0.200000, 0.057150)`，**法向为 (0, +1)（沿 y）**，
> **不满足本用例"接触法向沿 x"的要求**（两条解的**碰撞参数相同**（都 = `2r·sin45° = 0.040411`），
> 所以看着像，但**法向差 90°**，是**不同构型**）。
> ⇒ **在本用例的约束下只有 `y0 = 0.34285` 一个解。**
> ⇒ **不得再据本处重推**。（该假声明的源头是"采信未核"，与代码无关。）

**接触法向 `n̂` = (−1, 0)**（**按 §4.2 的定义 `n̂ = normalize(p_i − p_k)`，即由 B 指向 A**）。
> ⚠ **原写 `(+1, 0)`（"沿 A→B"）与 §4.2 的定义差一个符号** —— 已复算：主解首次接触点为 `(0.142850, 0)`，
> `p_A − p_B = (−0.05715, 0)` ⇒ **`n̂ = (−1, 0)`** ⇒ **§4.2 的定义为准，此处已改**。
> 判据只看 `|θ|` 故不阻塞，但**出射速度的符号依赖它** ⇒ 全 spec **写死一套**。
**分量分解 —— ⚠ 本节写死，避免再踩**：§2.4 公式里的 **`vx` 是法向分量、`vy` 是切向分量**：

```
入射速率 s ⇒ v_n = s/√2（沿 n̂）、v_t = s/√2（沿 t̂，方向 (0,−1)）
即 §2.4 的 (vx, vy) 取 (s/√2, s/√2)
期望分离角 θ = atan2( v_t , v_n(1−e)/2 ) = atan2( 1 , (1−e)/2 ) = atan( 2/(1−e) )
```

| --- | --- | --- | --- |
| **T16a** | **1.00** | **90.000°**（严格） | `|θ − 90°| ≤ 0.01°` |
| **T16b** | **0.95** | `atan2(vy, vx(1−e)/2)`，`vx=vy=v` ⇒ **88.567°** | `|θ − 期望| ≤ 0.05°` |

### T17 `e_ball` 的**敏感**判据（补 `T15`/`T16a` 的"对 e 不具信息" —— 本 spec 的核心补强）

**T17a 法向相对速度**：同 T16 的 45° 发射，两档 `e = 1.0 / 0.95`，断言
`v_rel,n′ = e · v_rel,n`（相对误差 ≤ 1e-4）。
**能测出**：`e_ball` 被写死 1（两档结果相同 ⇒ 失败）、`e` 未应用、冲量单边。

**T17b 动能耗散量（甲类闭式）**：等质量对心，`v_rel,n = v`，断言

```
ΔKE / KE_before = −(1 − e²)/2
e = 0.95 ⇒ −4.875%        e = 1.00 ⇒ 0%
```

**判据**：相对误差 ≤ 1e-4。

### T21 全局事件循环的自守卫（**本轮新增的硬门**，见 §9 `R-L`）

| # | 不变量 | 门槛（**必须可判定**） |
| --- | --- | --- |
| 1 | **`T24`/`T26` 构型**（**2 球 + 1 段**，断言 `ToiIterationGuardTrips == 0`）。<br>⚠ **原写"密集多球场景（3 球近距）"与构型不符**（`T24` 没有第三个球）⇒ 已删"密集"字样；**密集多球场景（8–16 球）本轮无任何判据**（见 §9 `R-L` 适用范围） | `== 0` |
| 2 | `BallBallMaxIterationsObserved` **既要有下界也要有上界** | **`1 ≤ 峰值 ≤ 0.5 × MaxToiIterations`** 即 `1 ≤ 峰值 ≤ 64` |
| 3 | T18b 判据 `0.5·v_rel·dt_sub` 随 `SubSteps` 联动：断言 `0 < 0.5·v_rel·dt_sub < v_rel·dt_sub` | 成立 |
| 4 | `SubSteps == DeriveSubSteps(MaxBallSpeed)`（沿用内核 I T6 判据 1） | 3 == 3 |

**`BallBallMaxIterationsObserved` 的统计口径（写死，不留解释空间）**：
**每个定长步（一次 `Step()`）内、所有子步的全局事件循环迭代数的最大值**；
`ResetDiagnostics()` 后归零；测试读的是**该步之后**的值。

**#1 为何要"定义场景"**：原写"密集多球场景"而**未定义** ⇒ 判据无法判定（也等于没声明覆盖）。
现直接绑定 `T24`（可构造、可判定）。

> **`#2` 下界 `≥ 1` 的语义（`R15`，勿误读）**：它测的是"**全局事件循环至少跑过一轮**"，
> 而**球-库边事件也会让循环跑** ⇒ **它不证明球-球事件发生**（后者由 `BallBallContactCount` 承担）。

**#2 为何要"下界 + 上界"**：
- **只写"< 128"**：`0 < 128` ⇒ "余量极大" ⇒ 通过，**即使球-球根本没实现**（空转）；
- **只写"≥ 1"**：贴边消耗到 127 也能过 ⇒ **没在守"余量"**；
- ⇒ 取 **`1 ≤ 峰值 ≤ 0.5 × MaxToiIterations`**。落在此区间之外时，按 §9 `R-L` 的**已授权处置路径**处理。

**为什么必须有 #2**：`MaxToiIterations` 的语义本轮变了（§0.3）。**"恰好没过 128"与"远低于 128"是两件事** ——
前者意味着预算被贴边消耗，换一个更密的球堆就会翻车。**必须留下可观测余量**，而不是只断言"没超"。

### T22 深层初始重叠的确定处置（防静默）

构造 `|Δp| = 2r − 5e-4 m`（**低于校验期阈值 1e-4 的 5 倍**，即越界态），断言：
① 不产生 NaN；② 首次子步后间距 ≥ `2r − 1e-6 m`（被分离）；③ `BallBallContactCount ≥ 1`（**不静默**）；
④ 两球法向相对速度反向。
**能测出**：深层重叠时 TOI 无根却直接放行（静默穿透）、位置修正缺失、除零。

> ⚠ **"评估时机 = 子步开始"必须可断言**（§2.6 的规则如此定义）。
> 若实现把它挪到"子步末"，`T22` 会走到**另一个分支**却**仍然"通过"** ⇒ 本判据失去意义。
> ⇒ 要求实现**暴露或可由测试推导**"本子步是否走了深层重叠分支"，并**断言它确实走了**。

**顺带（`R-P` ②）**：`§4.2` 的**球心重合退化分支**（`|Δp| < 1e-9`）目前**零覆盖**，
而 `T22` 走的是"浅重叠"分支 ⇒ **需另加一条极端用例**（两球心几乎重合），断言无 NaN、被确定性分离。

### T23 三球链式接触（**先后链式**，非"同刻" —— 标题已更正）

> ⚠ **标题勘误**：原标"同时刻多接触"与本构型**不符** —— B 与 C 间距 `2r + 1e-4` ⇒ **先后接触（链式）**，
> **不产生"同一 `t` 的多接触"**。若把 `R-M` 的缓解挂在本用例上，就等于
> "**有风险登记、无测试兜住**"（内核 I「76 段袋角零覆盖」的换皮重现）。
> **真正的同刻覆盖见 `T24`。**

球 A 撞 B，B 紧邻 C（间距 `2r + 1e-4`），`e = 1.0`。断言：
① 动量守恒 ≤ 1e-6（**本用例合法**：三球链**全程无库边接触**、库不参与 ⇒ **无外部约束，总动量守恒成立**；对比 `T24`/`T26` 含库边 ⇒ 那里**不得**断言总动量守恒，见 §5 T24）；② `EnergyGainViolations == 0`；③ **不出现"B 被解算两次"**（由计数与末速对照甲类判断）；
④ `ToiIterationGuardTrips == 0`；
⑤ **`BallBallContactCount ≥ 2`**（三球链至少两次接触 —— **没有它，球-球完全未实现也能通过**）。
**能测出**：链式多接触的顺序解算、同一对重复解算（双倍冲量）。
**测不出（盲带）**：真·同刻多接触（见 T24）；`e_ball` 取值。

### T24 库边夹心：**同一子步内球同时接触球与段**（`R-M` 的真实覆盖）

**构造（甲类、可判定）**：取一条直库段 `S`。把球 B **静止**放在**距 `S` 恰为 `r`** 的位置（B 贴库）；
球 A 沿 `S` 的**法向**、从 B 的外侧对准 B 撞来。

> ⚠ **摆放的浮点边界（本用例直接踩在上面）**：`|s0|` 在 float 下可能是 `r ± ε`。
> **两种符号都必须被确定处置**（见 §2.6 新增行）：`≥ r` 一侧走"进入根 `t = 0`"；
> `< r` 一侧（已重叠）走**与球-球同一套深层重叠处置**。
> ⇒ 实现**不得只处理一侧**；测试应**分别构造三种摆放**各跑一次：
> **① `r`（恰贴）、② `r − 1e-6`（float 噪声档）、③ `|s0| = 0.5r`（深层重叠档 —— `R11`）**。

> **为何必须加第 ③ 档（`R11`）**：`r − 1e-6` 只覆盖 **float 噪声**（float32 在 1.27 m 处 ULP ≈ `6e-8`，
> 实际远小于 `1e-6`）；而**位置修正可把球推入库边远超 `1e-6`**（球-球重叠可达 `2r`）
> ⇒ **`|s0| ≪ r` 原为零覆盖** ⇒ 必须补 `0.5r` 这一档，否则"球被推入深重叠后不穿库"无人守。
⇒ A 接触 B 的那一刻（`|A − B| = 2r`），**B 同时距 `S` 恰为 `r`** ⇒ B **同时**与球 A 和库段 `S` 接触。

**参数（**写死**，保证可复现 —— `R6`）**：`e_ball = 1.0`、`e_cushion = 1.0`、`μ_cushion = 1.0`。
> 为何 `e_cushion = 1.0`：本用例要探的是"**顺序解算升能**"，而升能只在**弹性反射**下才可能显现；
> 取 `e_cushion < 1` 会把库边耗散混进来，**反而掩盖**要探的现象。

**本用例拆两档 —— 因为两个断言对 `e_cushion` 的要求相反（`R2`）**：

| 档 | `e_cushion` | 查什么 |
| --- | --- | --- |
| **T24a** | **1.0** | 升能 / 迭代守卫 / 球-球计数 / **顺序路径签名** / **B 不穿库** |
| **T24b** | **0.0** | **动量转移的可观测推论**（替代原"动量守恒"） |

> **⚠ 原断言 ②「动量守恒 ≤ 1e-6」已删除（`R2`：**不可满足条款**）**：
> 本用例里 **B 撞的是库段**，库是**外部约束** ⇒ `Step()` 后 `p_A + p_B` **必然改变** ⇒
> **正确实现也会 FAIL**（本工程专门防这一类）。
> ⇒ 改为**作用域限定**的"**球-球冲量等大反向**"，并取 `e_cushion = 0`（墙把 B 的动量**全部吸收**）：
> 等质量 + `e_ball = 1` + 对心 ⇒ **A 把全部动量交给 B，B 又全部交给墙** ⇒
> **A 的末速应 ≈ 0** —— 这就是"冲量等大反向"的**可观测等价式**。

**T24a 断言（`e_cushion = 1.0`）**：
① `EnergyGainViolations == 0`；
② `ToiIterationGuardTrips == 0`；
③ **`BallBallContactCount ≥ 1`**（非空转）；
④ **"顺序路径"的可观测签名**：同一 `Step()` 内 **`BallBallMaxIterationsObserved ≥ 2`** ——
   B 的段接触以 `t = 0` **紧跟**球-球事件 ⇒ **至少两轮迭代**（正是"零时间推进"的可观测签名）；
⑤ **B 不穿库（`R10`）**：末态 `distance(B, 段 S) ≥ r − 1e-6 m`
   —— 段接触若**静默失效**（球钻入库边），本断言会抓住。

**T24b 断言（`e_cushion = 0.0`）**：
① **`|v_A末| ≤ 1e-4 m/s`**（A 静止 —— 见上"可观测等价式"）；
② `BallBallContactCount ≥ 1`；③ `ToiIterationGuardTrips == 0`。

> **⚠ 原断言 ⑤「记录两个接触的绝对时刻，断言其差 ≤ `ToiTimeEpsilon`」已删除（`R3`：**不可判定**）**：
> `§3.2` 只暴露 3 个球-球诊断，且**明写"测试不需要新增读取 API"** ⇒ **没有任何途径读到"接触的绝对时刻"**；
> 而 `§12` 又把它列为"须独立核验" ⇒ 会产生"**一个不可观测的判据被当成已核验**"。
> ⇒ 按 **(a) 路线**换成上面的第 ④ 条**可观测等价式**（不新增 API，与 `§3.2` 保持一致）。
> **不选 (b)**（新增"接触时刻"API）：那会让 `§3.2` 那句变成**自相矛盾**，且为一条判据扩大产品接口。

> **盲带（`R9`，如实声明）**：**本用例只抓"危险顺序"** —— 即"B 先获朝墙速度、再被墙反射"导致的顺序解算升能；
> 若实现恰好按"**段先于球-球**"解算，可能**不升能** ⇒ ① 通过。
> ⇒ **它证明"该顺序危险"，不证明"顺序正确"** ⇒ **判别力真实但窄**。

**能测出**：同刻/零时间推进下的顺序解算升能、"顶穿"（T24a⑤）、动量转移（T24b）。
**测不出**：`e_ball` 取值；**"归并进同一 group"** 那一类 ⇒ 见 `T26`。

### T25 候选对完备性（§2.7 的接口守卫）

小规模（4 球）下断言：候选对产生函数的产出**与暴力枚举逐元素一致**（**含顺序**）。
**期望（甲类）**：4 球 ⇒ **6 对**，顺序 `(0,1) (0,2) (0,3) (1,2) (1,3) (2,3)`。
**函数是否做距离过滤（`R14`，必须写明）**：本轮 `CollectCandidatePairs` **不做任何距离过滤** ——
它就是**双层暴力循环**、产出**全部 `n(n−1)/2` 对** ⇒ 期望值**不依赖球位摆放**。
（若将来引入过滤，本用例的期望值必须随之改写并记录。）

**⚠ 判别力声明（同一算法，必须写明）**：本轮 `CollectCandidatePairs` **就是**双层暴力循环，

**只抓"编码 bug"（漏写一对、顺序错），抓不到"算法不完备"** ⇒ **判别力真实但窄**。

**能测出**：漏对 / 顺序错（编码 bug）；将来换网格法后的**静默漏对**。
**盲带**：① 不覆盖"产出被正确消费"；② 不覆盖 `n ≤ 1` 的退化（0 对）；③ 大规模剪枝本身的正确性。

（`R13` 说明：独立复核逐条原子化后确认 **「丙 = 0」成立**，但原表有 3 条被标成"甲"、实为
**乙 / 乙(系数选定)** —— 已逐一更正。另据量级估算：三构型每子步迭代数约 `1–2 / 3–4 / 3–5`
⇒ `≤ 5 ≪ 64` ⇒ **余量 ≥ 12×，不会假失败** ✓）

### T26 库边 + 球：**同一时刻归并进同一 group**（`R-M` 的另一半覆盖）

`T24` 只覆盖"**零时间推进 + 顺序解算**"；**未覆盖 `§2.2` 步骤 4 的"同一 group 内段 + 球-球顺序解算"**。
本用例补上那一半（几何已独立复算）。

**构造（甲类、可判定）**：

```
取一条直库段 S：直线 y = 0，内侧法向 +y（球在 y > 0 一侧）
球 B = (0.20, r) 静止                     # r = 0.028575
球 A0 = (0.09285, 0.078575)，速度方向 (1, −1)
⇒ Δx = 0.05 时 A = (0.142850, 0.028575)
   · 距段 S = |0.028575| = r        ✓ 与段接触
   · |A − B| = 0.057150 = 2r        ✓ 与球 B 接触
⇒ 两个接触发生在同一 t ⇒ **归并进同一个 group** ⇒ 走"group 内顺序解算"路径
```

**参数（写死）**：`e_ball = 1.0`、`e_cushion = 1.0`、`μ_cushion = 1.0`。

**断言**：
① `EnergyGainViolations == 0`；
② **球-球冲量等大反向**（**作用域限定到球-球那一对**；**不得**断言含库边的总动量守恒，理由见 `T24`）；
③ `ToiIterationGuardTrips == 0`；
④ **`BallBallContactCount ≥ 1`**（非空转）；
⑤ **`TotalContactCount ≥ 2`**（该子步内段接触与球-球接触**都**发生了 ⇒ 佐证"两者在同一 group"）；
⑥ **B 不穿库**：末态 `distance(B, S) ≥ r − 1e-6 m`。

**覆盖声明（如实）**：本用例覆盖 **group 归并**那一类；
**`T24`（零时间推进）+ 本用例（group 归并）合起来才算 `R-M` 全覆盖**。

**盲带**：对 `e_ball` 取值不敏感；"group 归并是否真的发生"由 ⑤ **间接佐证**，
**不是**直接观测"两个 `t` 相等"（后者不可观测，理由见 `T24`）。
