## 0. 本轮变更摘要

### 0.1 权威范围（照抄排期，不放宽）

> **Day 5 — 物理内核 II：球-球碰撞（8 h）**
> 1. 等质量弹性碰撞：法向冲量分解 + 恢复系数 + 切向摩擦传递（2.5 h）
> 2. 接触判定与分离（防抖动、防粘滞）（2 h）
> 3. 空间划分：16 球用 O(n²) 足够，但**接口留好**（后续 AI 推演会放大调用量）（1 h）
> 4. 单测：对心碰撞速度交换、斜碰约 90° 分离角、动量守恒（2.5 h）
>
> **验收**：三项单测全绿　**注意**：Day 5 前系统里**没有** 8 球规则，只有"物理上正确的碰撞"

### 0.2 为什么必须先出 spec

内核 I 的验收里，**「反射角 < 1°」单独使用没有判别力**（`e` 被写死成 1 时角度照样守恒）。
球-球这一轮有**完全同族**的坑，而且更隐蔽：

| 排期给的检查项 | 能测出 | **测不出** |
| --- | --- | --- |
| 对心碰撞速度交换 | 未解算球-球接触、法向错 | `e_ball` 被写死成 1（交换本来就只对 e=1 成立） |
| 斜碰约 90° 分离角 | 法向错、分量分解错、**μ 污染法向** | **`e_ball` 的任何错误**（90° 只在 e=1 成立） |
| 动量守恒 | 冲量不对称、单边解算 | `e_ball` 取错（任何 e 都守恒）；**能量耗散量** |
| —（排期未列） | — | **穿透**：球-球若不做 TOI，高速对开会互相穿过 |

⇒ **四项必须成套**，另补**穿透**一项。本 spec §5 的测试族即为补齐这五列而设计；
其中「90° = 90°」这条**不得**被当作 `e_ball` 的检出保证（理由见 §2.4，含推导）。

### 0.3 本轮最重的一条：**事件循环的作用域必须从"单球"改成"全局"**

内核 I 的 `Step()` 是 **逐球独立积分**：

```
Step() → for sub in SubSteps → for i in balls → IntegrateBall(i)     // 每球走完整的子步
```

`EarliestToi` 只遍历**段**，`ResolveContact` 只解算**段接触** ⇒ **球与球之间完全没有相互作用，
会直接互相穿过**。而球-球接触在几何上是**一对球的共同事件**，无法在"逐球独立"的框架里表达。

⇒ **必须把子步内的事件循环提升为"全局最早事件"**（§2.2）。这是本轮的**架构变更**，
也是最大的一处风险来源（§9 `R-L`）：它**改变了 `MaxToiIterations` 的语义**
（"每球每子步"→"每子步全局"），因此内核 I 那句"预算 128 ⇒ guardTrips=0"的实测依据**不再直接适用**，必须重验。

## 1. 既定事实（读当前代码 + 解析计算，非推断）

### 1.1 当前内核**没有**球-球建模（逐行确认）

| 位置 | 现状 | 后果 |
| --- | --- | --- |
| `PoolSimulator.Step` | `for sub → for i(_balls.Length) → IntegrateBall(i)` | 每球独立走完整个子步 |
| `PoolSimulator.IntegrateBall` | 只调 `EarliestToi`（段）与 `ResolveContact`（段组） | 球之间无任何耦合 |
| `EarliestToi` | `for i in _segA.Length` | **只找段**，不找球 |
| `ResolveContact` | `for g in group`（段索引） | 只解算段接触 |

⇒ **两球相向运动会互相穿过**，且不会有任何计数器报警（静默）。这是本轮要修的核心缺口。

### 2.1 单一口径参数表（唯一真源，实现不得自行造值）

| 参数 | 落点 | 语义 | Day 5 取值 | **是否运行时真源** |
| --- | --- | --- | --- | --- |
| `ballRestitution` | **`PhysicsParams`** | 球-球**法向**恢复系数 `e_ball`，[0,1] | **可配**；单测**参数化跑 1.0 与 0.95** | ✅ 是（运行时可调） |
| `ballTangentialFriction` | **`PhysicsParams`** | 球-球**切向**保留系数 `μ_ball`，[0,1] | **钉死 1.0**（理由见 §2.5） | ✅ 是，但**本轮只允许取 1** |
| `ballInitialOverlapTolerance` | **`PoolSimulator`** 常量 | 合法初始摆放的两球间距下限：`|Δp| ≥ 2r − 该值` | **1e-4 m** | ❌ 否（**校验期**常量，不参与积分） |
| 球-球 TOI 归并窗口 | **复用 `ToiTimeEpsilon`** | 球-球同刻接触与段接触**共用同一窗口** | 1e-9 s | ✅ 是 |
| 球-球位置修正系数 | **`PoolSimulator`** 常量 | 重叠分离时两侧**各推一半** | 0.5 / 0.5 | ✅ 是 |
| 宽相位模式 | **实现细节，不进参数表** | 本轮固定 O(n²)（§2.7） | — | ❌ 否 |

**口径一致性要求**（与内核 I 同源）：
- `e_ball` 与 `μ_ball` **各自独立作用于各自分量**，**不得**合并为"先反射再统一缩放"
  （那会把 `μ_ball` 乘到法向分量上 —— 内核 I 已记录该陷阱）。
- `e_ball` **不得**与库边的 `cushionRestitution` 共用一个字段：两者是**不同接触对**的物理量，
  库边是"球 vs 静态墙"，球-球是"球 vs 等质量球"。合并会让"只改库边手感"污染球-球行为。

### 2.2 架构：子步内**全局最早事件**循环（本轮唯一架构变更）

**现状（内核 I）**：`Step → for sub → for i → IntegrateBall(i)` —— 每球走完整个子步。

**本轮**：把"子步内"提升为**全局事件循环**：

```
子步推进(Δ):
    remaining = Δ
    iterations = 0
    while remaining > ToiRemainingEpsilon:
        if ++iterations > MaxToiIterations: 守卫计数++; break

        # 1) 全局最早事件：段接触 与 球-球接触 一起搜
        earliest = +inf; 事件 = 空
        for i in 球索引升序:                     # ← 保留升序球遍历（D-3 依赖）
            for j in 段索引升序:
                t = SolveToi(p_i, vAvg_i, seg_j, r)
                若 t ∈ [0, remaining] 且是"进入"接触 → 候选(i, j)
        for i in 球索引升序:
            for k in (i+1)..n 升序:
                t = SolveBallBallToi(p_i, vAvg_i, p_k, vAvg_k, r)
                若 t ∈ [0, remaining] → 候选对 (i, k)

        # 2) 若无事件：全部活跃球自由飞行到子步末，结束
        if 无候选:
            for i 升序: p_i += vAvg_i * remaining
            break

        # 3) 归并同刻事件（|t − earliest| ≤ ToiTimeEpsilon），**全部活跃球**推进到 earliest
        for i 升序: p_i += vAvg_i * earliest
        remaining -= earliest

        # 4) 解算该时刻的接触组（段组按段索引升序；球-球对按 (i,k) 升序）
        解算接触()

        # 5) 近零速度 / 连续两次零时间推进 两个即停判据（沿用内核 I，扩展到全局）
        ...

        # 6) 按新速度重取各球 vAvg（若 a > 0）
```

**为什么必须"推进所有球"而不是只推进参与事件的球**：`earliest` 是**全局**最早接触时刻；
其余球在 `[0, earliest)` 内无事件，必须同样前进，否则时间轴在球之间错位。

**备选方案与为何不选**：

| 备选 | 描述 | 为何不选 |
| --- | --- | --- |
| **B. 保留逐球循环，球-球只在子步末做一次采样重叠解算** | 改动最小 | ① 重叠可达 **44 mm**（§1.3），与 ≤1e-5 m 的标准差 4 个数量级；② 解算顺序依赖"哪只球先被访问"，**确定性脆弱**；③ 高速对开在子步内已穿越，**无法事后修复** |
| **C. 只对球-球做 TOI，段接触仍逐球** | 折中 | 两条时间轴（球的段事件 vs 球对事件）无法归并 ⇒ **同刻多接触**（球同时撞段与撞球）会漏解算，直接放大内核 I 的 `R-C`（角点升能） |
| **D. 用固定小步长（把 `SubSteps` 提到 300+）代替 TOI** | 简单 | 内核 I 已实测：把自由飞行误差压到 1e-5 m 需 `SubSteps ≥ 3333`；且**改变既有验收数量级**，等于推翻内核 I 的结论 |

⇒ **采用全局事件循环**。它与排期第 3 条"O(n²) 足够，接口留好"不冲突（宽相位见 §2.7）。

### 2.3 球-球 TOI 的解析解（第一性原理）

两球（半径同为 `r`）在子步内以**常均速** `v_i`、`v_k` 运动。设相对量：

```
d  = p_i − p_k        (相对位置)
w  = v_i − v_k        (相对速度)
接触条件： |d + w·t|² = (2r)²
展开：     |w|²·t² + 2(d·w)·t + (|d|² − 4r²) = 0
```

```
A = |w|²,  B = 2(d·w),  C = |d|² − 4r²
若 A ≤ 0            → 无相对运动 ⇒ 无接触（返回 +∞）
disc = B² − 4AC < 0 → 无实根 ⇒ 无接触
t = (−B − √disc) / (2A)          # 较早根 = "进入"时刻
```

**接受条件**（三条全满足才接受）：
1. `t ∈ [0, remaining]`（本子步内、未过期）；
2. **接近**：`d·w < 0`（两者在靠近）。等价地：接触点相对法向速度 `< 0`。
   这一条与内核 I `RayCircleToi` 的"仅接受进入"同构 —— **否则已分离的球会在 t=0 反复自触发**；
3. 反向校验：用 `normalize(d + w·t)` 复核接触法向与相对速度相反（浮点保护）。

**与段 TOI 的关系**：两者**共用** `ToiTimeEpsilon` 归并窗口，进入**同一个** `earliest` 竞争。
⇒ 球同时撞库边与撞球（三体同刻）会被归并成一组统一解算 —— 这正是内核 I `R-C` 家族的放大场景（§9 `R-M`）。

### 2.4 「斜碰 90°」的真伪与它的**判别力边界**（本节独立推导，不复述实现）

等质量 `m`、球 k 静止、接触法向沿 x。设球 i 入射 `(vx, vy)`、恢复系数 `e`：

```
v_i′ = ( vx(1−e)/2 ,  vy )          v_k′ = ( vx(1+e)/2 ,  0 )
```

**分离角**（`v_k′` 恒沿 +x，故夹角 = `v_i′` 的极角）：

```
θ(e) = atan2( vy , vx(1−e)/2 )        ← 甲类闭式解（本 spec §5 T16 的期望值来源）
v_i′·v_k′ = vx²(1−e²)/4   ⇒   θ = 90°  ⟺  e = 1
```

| e | `v_i′` | θ（`vx = vy = v`） |
| --- | --- | --- |
| **1.00** | `(0, v)` | **90.000°**（严格） |
| **0.95** | `(0.025v, v)` | **88.567°** |

⇒ **两条硬结论**：
1. **「约 90°」不是普适常数，它依赖 e。** 容差按 ±0.5° 写会对 e=0.95 档**假失败**；按 ±2° 写等于没验。
   ⇒ 故用户已拍板"两档都做"：`e=1` 档给**严格判据**，`e=0.95` 档给**甲类解析判据**。
2. **该判据的判别力随 e 偏离 1 而单调下降。** 对 e 敏感的判据**不是**角度，而是
   **沿法向的相对速度**与**动能耗散量**：

```
法向相对速度：  v_rel,n′ = e · v_rel,n        （e 从 1→0.95 时该量单调变化 5%）
动能耗散（等质量）：ΔKE = −(1−e²)·m·(v_rel,n)²/4
e=0.95, v_rel,n = v ⇒ ΔKE/KE = −(1−e²)/2 = −4.875%
```

⇒ **本 spec 把"`e_ball` 是否正确"交给 T17（动能耗散量，甲类闭式）**，而不是交给角度。
**这是"不要把有盲带的检查当检出保证"的直接应用**（§5 每条判据都要求声明盲带）。

### 2.5 `μ_ball` 在本轮为什么必须钉死为 1（请在评审里重点挑战）

排期第 1 条写了"**切向摩擦传递**"。但本轮**没有自旋建模**（自旋/塞明确属后续轮次）。
在**无自旋**的等质量光滑球模型里，球-球接触的切向**没有物理耗散通道**：

- 切向冲量需要**角动量汇**（球开始旋转）才能守恒；没有角自由度，任何 `μ_ball < 1`
  都会**凭空耗散切向动能** ⇒ 破坏"动量守恒 + 能量不增"二者的物理含义（能量"不增"会更宽松地成立，
  即该参数**只会制造假通过**，不会制造失败）。
- 且 **90° 判据本身就要求 `μ_ball = 1`**：`μ_ball < 1` 会把 `v_i′` 的切向分量额外缩短，
  使"90°"这一条**同时依赖两个参数**，判据不再干净。

⇒ **本轮 `μ_ball = 1`（无切向损耗）**，参数**保留在结构里**并在注释里写明
"允许 ≠1 的条件是引入自旋之后"。排期的"切向摩擦传递"因此**降级为本轮不实现**，
并在 §8 明确非目标 + §7 ⑦ 项请用户确认。

### 2.6 接触判定与分离（防抖动、防粘滞）—— 排期第 2 条

| 机制 | 规则 | 为什么需要 |
| --- | --- | --- |
| **位置修正** | 解算后若两球仍重叠（`|Δp| < 2r`），沿 `n̂` **各推一半**，使间距 = `2r` | 不修正 ⇒ 下一迭代立刻再触发同一对接触（抖动/粘滞） |
| **近零速度即停** | 沿用 `StoppedSpeedEpsilon`（扩展到全局循环） | 接触解算按 `e^{2k}` 几何衰减，**永不精确为 0**（内核 I 实测） |
| **连续两次零时间推进即停** | 沿用内核 I 的第二半修复 | 球楔死在凹角/夹在两球之间时，`earliest = 0` 且 `remaining` 不减 ⇒ 空转 |
| **初始重叠（合法边界）** | **不在运行时夹断**；由校验期拒绝 `|Δp| < 2r − 1e-4 m` 的初始摆放 | 与库边的"贴库静止球"同族：合法摆位可落在边界上，抛异常会把合法局面判死 |
| **深层重叠的确定处置** | 若子步**开始时**已 `|Δp| < 2r`（越过了校验期，例如被位置修正推入），TOI 无未来根 ⇒ **立即按 `n̂ = normalize(Δp)` 解算一次接触并做位置修正**，计一次接触 | **不得静默**：否则两球会带着重叠继续各自飞（相当于静默穿透） |
| **单一对只解一次** | 同一次事件里，同一个球对**只解算一次**（即使被多次判为同刻） | 防止双倍冲量 |

### 2.7 空间划分：O(n²) + **一个函数边界**（排期第 3 条）

本轮固定 **O(n²)**：16 球 ⇒ **120 对**，每子步 3 次 ⇒ 360 次配对求交，可忽略。

**"接口留好"的准确含义（本 spec 的收敛解释）**：
> 把"候选球对"的产生收敛到**一个函数**（如 `CollectCandidatePairs`），**本轮实现为双层升序循环**。
> 后续（AI 推演放大调用量时）可**只替换该函数体**为网格/扫描-剪枝，**调用方与顺序语义不变**。

**明确不做**：不引入 `IPairProvider` 接口/泛型/委托 —— 那是**为假想的第二实现付抽象成本**，
而当前只有一个实现，且替换点已被一个函数隔离。

## 4. 求解过程 spec

### 4.1 子步（见 §2.2 伪码）；**位置与 TOI 共用同一 `v_avg`**（内核 I 既有要求，本轮不变）

### 4.2 球-球接触解算（等质量）

对每个球对 `(i, k)`，**按 (i,k) 升序**：

```
d  = p_i − p_k
n̂  = normalize(d)                    # 由 k 指向 i
     ├─ 若 |d| < 1e-9 → 退化（球心重合）：取 -normalize(v_i − v_k) 为 n̂；仍为零则取 (1,0)
v_rel = v_i − v_k
v_n   = dot(v_rel, n̂)                 # n̂ 指向 i ⇒ v_n < 0 表示 i 正在靠近 k
若 v_n ≥ 0: 跳过（已在分离，不产生冲量）      # ★ 与"仅接受进入"同构

J = −(1 + e_ball) · v_n / 2           # 等质量 ⇒ 各承担一半冲量；m 归一化后即此式
v_i += J · n̂
v_k += −J · n̂

# 切向：μ_ball = 1 ⇒ 切向分量不变（无自旋模型下无切向冲量）
# 若将来 μ_ball < 1，必须在此处独立赋值切向分量，且不得污染 v_i/v_k 的法向分量
```

**等质量闭式校验**（供评审对照，不复用实现公式）：
> `v_i′ = v_i − J n̂`、`v_k′ = v_k + J n̂`，其中 `J = (1+e)(v_k − v_i)·n̂ / 2`。
> 代回即得 §2.4 的 `v_i′ = (vx(1−e)/2, vy)`、`v_k′ = (vx(1+e)/2, 0)`（k 静止、n̂ = x̂）。

**位置修正**（防抖动）：
```
overlap = 2r − |d|
若 overlap > 0:  p_i += (overlap/2)·n̂ ;  p_k −= (overlap/2)·n̂
```

### 4.3 不变量（沿用内核 I 的两组划分，本轮扩到球-球）

**组 ①：模型内自洽（必须精确成立）**

| 不变量 | 断言 |
| --- | --- |
| 球-球接触后间距 = 2r | `|dist(C_i, C_k) − 2r| ≤ 1e-6 m` |
| 球-球法向相对速度反向且衰减 | `v_rel·n̂` 符号翻转；`|v_rel′·n̂| ≤ e_ball·|v_rel·n̂| + 1e-6` |
| 球-球动量守恒（等质量） | `|v_i′ + v_k′ − (v_i + v_k)| ≤ 1e-6`（绝对，m 归一化） |
| 无升能（球-球） | `KE_out ≤ KE_in·(1 + 1e-6)`，计入 `EnergyGainViolations` |

**组 ②：模型 vs 真值（只能实测/解析，不得仅凭公式声称）**

| 量 | 甲类来源 |
| --- | --- |
| 分离角 | `θ(e) = atan2(vy, vx(1−e)/2)`（§2.4） |
| 动能耗散 | `ΔKE = −(1−e²)m(v_rel,n)²/4`（§2.4） |
| 对心交换 | `e=1` ⇒ 速度完全交换（一维弹性等质量） |

## 5. 测试族（T 编号续内核 I，自 **T15** 起）

> 坐标系：规范二维物理平面，x 长轴、y 短轴，单位米。球半径 0.028575 m，`dt = 1/120 s`，`SubSteps = 3`。
> **每条期望值必须来自解析闭式或独立推导，不得读取模拟器内部量。**
> **每条必须声明「能测出什么 / 测不出什么 / 盲带」。**

### T15 对心碰撞：速度交换（排期三项之一）

**发射状态**：球 A `(−0.20, 0)`、`v = (+1, 0)`；球 B `(+0.20, 0)`、`v = (0, 0)`；`e_ball = 1.0`、`μ_ball = 1.0`。
间距 0.40 m ≫ 2r，避免初始重叠。

**期望（甲类）**：一维弹性等质量 ⇒ **完全交换**：`v_A′ = (0,0)`、`v_B′ = (+1, 0)`。

- **判据**：相对误差 ≤ **1e-4**
- **能测出**：球-球接触完全未解算（球会互穿，`v_B′` 仍为 0）、法向取错、冲量单边施加
- **测不出**：`e_ball` 的取值（交换只在 e=1 成立 ⇒ 该测试**只对 e=1 档有效**，见 T16/T17）
- **盲带**：`e_ball` 与 1 的偏离 < 1e-4 时与"写死 1"不可区分（由 T17 补）

### T16 斜碰分离角（排期三项之二，**两档参数化**）

**发射状态**：球 B 静止于 `(0.20, 0)`；球 A 自 `(-0.20, 0.40)` 以 `v = (1, −1)` 入射（**45° 入射**，
接触法向沿 x）。`μ_ball = 1`。

| 档 | `e_ball` | 期望 θ（甲类） | 判据 |
| --- | --- | --- | --- |
| **T16a** | **1.00** | **90.000°**（严格） | `|θ − 90°| ≤ 0.01°` |
| **T16b** | **0.95** | `atan2(vy, vx(1−e)/2)`，`vx=vy=v` ⇒ **88.567°** | `|θ − 期望| ≤ 0.05°` |

- **T16a 的判据为何能取到 0.01°**：接触由**解析 TOI** 定位、解算为**瞬时应答**，
  速度不含离散化误差 ⇒ 角度应精确到浮点量级。若实测 >0.01°，指向**法向或分量分解**有误。
- **能测出**：法向取错、分量分解错、`μ` 污染法向、球-球 TOI 取到远根（接触时刻错 ⇒ 位置错 ⇒ 法向错）
- **测不出（盲带，必须写明）**：**`e_ball` 的任何错误**。θ 对 e 的一阶敏感度
  `dθ/de = 1/(1 + [2vy/(vx(1−e))]²) · (2vy/(vx(1−e)²))` 在 e→1 时 →0
  ⇒ **e 越接近 1，该判据越盲；e=1 时完全盲**。
  **⇒ 本判据不得被引用为 `e_ball` 的检出保证**（`e_ball` 的检出归 T17）。

### T17 `e_ball` 的**敏感**判据（补 T16 的盲带 —— 本 spec 的核心补强）

**T17a 法向相对速度**：同 T16 的 45° 发射，两档 `e = 1.0 / 0.95`，断言
`v_rel,n′ = e · v_rel,n`（相对误差 ≤ 1e-4）。
**能测出**：`e_ball` 被写死 1（两档结果相同 ⇒ 失败）、`e` 未应用、冲量单边。

**T17b 动能耗散量（甲类闭式）**：等质量对心，`v_rel,n = v`，断言

```
ΔKE / KE_before = −(1 − e²)/2
e = 0.95 ⇒ −4.875%        e = 1.00 ⇒ 0%
```

**判据**：相对误差 ≤ 1e-4。
**能测出**：`e_ball` 取错（该量对 e **一阶敏感**：`d(ΔKE)/de = e·m·v²/2 ≠ 0`）；
把 `e` 误当 1；把 `μ` 的错误混入法向。
**盲带**：对 `μ_ball` 完全盲（本轮 `μ_ball ≡ 1`，故不影响）。

### T18 球-球无穿透 / 无嵌入（含负对照）—— 排期未列，但**必须做**

**T18a 正向**：两球对开，各自 `|v| = 8 m/s`（相对 16 m/s），初始间距 ≥ 0.5 m。断言全程：
- 两球间距**从不 < 2r − 1e-5 m**（即最大重叠 ≤ **1e-5 m**）；
- `ToiIterationGuardTrips == 0`、`EnergyGainViolations == 0`。

**T18b 负对照**：`DisableBallBallToiForDiagnosticsOnly = true`，同一发射，断言
最大重叠 **≥ 0.5 · v_rel · dt_sub**（公式化，非写死常数）。

| `SubSteps` | `v_rel·dt_sub` | 判据 `0.5·v_rel·dt_sub` |
| --- | --- | --- |
| 3（当前） | 44.444 mm | **≥ 22.222 mm** |

> **为什么公式化**：内核 I 的 T5b 最初写死 `≥2e-2 m`，在 `SubSteps` 升到 4 时即落空 ⇒ 制造"不可达条款"式假通过。
> 本轮直接沿用公式形式，并把 `0.5·v_rel·dt_sub` 的联动写进 T21 的自守卫。

**能测出**：球-球 TOI 缺失/取远根/取错根、只在子步末采样、位置修正缺失。
**测不出**：`e_ball`（`e` 不影响是否穿透）。

### T19 动量守恒（排期三项之三，**两档参数化**）

**T19a**：同 T16 的 45° 发射，两次运行 `e = 1.0 / 0.95`，断言
`|(v_A′ + v_B′) − (v_A + v_B)| ≤ 1e-6`（等质量、m 归一化）。
**能测出**：冲量不等大反向（单边施加、符号错、只在几何上"弹开"而未改速度）。
**测不出**：`e_ball` 取值（**任何 e 都守恒**）⇒ 排期这条**对 e 完全盲**，由 T17 补。

**T19b**（并入 T17b 的动能耗散，二者合起来才既守恒又耗散正确）

### T20 确定性（多球，扩内核 I 的 D-3 口径）

3 球（含一次球-球碰撞 + 一次撞库），同初态跑两次 `Step()` × 300，`position`/`velocity`
**逐位一致**（`float` 的 `R` 格式比较）。断言 `BallBallContactCount > 0`（**非空转**：证明确实发生了球-球接触）。
**能测出**：配对循环引入无序容器、位置修正依赖访问顺序、全局循环里球序不固定。

### T21 全局事件循环的自守卫（**本轮新增的硬门**，见 §9 `R-L`）

| # | 不变量 | 当前值 |
| --- | --- | --- |
| 1 | 密集多球场景 `ToiIterationGuardTrips == 0` | 0 |
| 2 | 记录 `BallBallMaxIterationsObserved`，并断言其 **< MaxToiIterations**（留出余量，非贴边通过） | 待实测 |
| 3 | T18b 判据 `0.5·v_rel·dt_sub` 随 `SubSteps` 联动：断言 `0 < 0.5·v_rel·dt_sub < v_rel·dt_sub` | 成立 |
| 4 | `SubSteps == DeriveSubSteps(MaxBallSpeed)`（沿用内核 I T6 判据 1） | 3 == 3 |

### T22 深层初始重叠的确定处置（防静默）

构造 `|Δp| = 2r − 5e-4 m`（**低于校验期阈值 1e-4 的 5 倍**，即越界态），断言：
① 不产生 NaN；② 首次子步后间距 ≥ `2r − 1e-6 m`（被分离）；③ `BallBallContactCount ≥ 1`（**不静默**）；
④ 两球法向相对速度反向。
**能测出**：深层重叠时 TOI 无根却直接放行（静默穿透）、位置修正缺失、除零。

### T23 三球链式接触（同时刻多接触，扩内核 I `R-C`）

球 A 撞 B，B 紧邻 C（间距 `2r + 1e-4`），`e = 1.0`。断言：
① 动量守恒 ≤ 1e-6；② `EnergyGainViolations == 0`；③ **不出现"B 被解算两次"**（由 `BallBallContactCount` 与末速对照甲类判断）；
④ `ToiIterationGuardTrips == 0`。
**能测出**：同刻多接触的顺序解算升能（内核 I `R-C` 的放大版）、同一对重复解算（双倍冲量）。
