### 缺陷 D2（中-高）「不累积」不成立 / 未论证，且与 §4.3 不变量量纲冲突
spec §2.1 写：*"单次接触点偏差 ≈ ½·a·dt_sub²，**不累积**（每个子步以当前速度为基准重新求解）"*。

**（a）「不累积」的理由不成立。** "每个子步从当前状态重新求解"恰恰意味着**位置误差被携带下去** ——
第 k 次接触留下的位置偏移 Δₖ 会**留在状态里**，与第 k+1 次的 Δ_{k+1} **相加**。
要让它"不累积"，必须有一个**把球重新投影回接触面**的步骤（把法向距离重新钉到 r，从而吸收该次误差）；
而 §4.1 的伪码里**没有这一步**（只有 `position += v·earliest`）。

**（b）与 §4.3 不变量量纲冲突。** §4.3 要求接触后 `|dist(C,seg) − r| ≤ 1e-6 m`（1 µm）；
而 §2.1 判据 B 允许单次接触点偏差 ≤ 5e-5 m（实测 19.29 µm）。**两者相差 ~20 倍，不能同时成立** ——
除非存在 (a) 中的重投影（那样法向误差每次被归零，§4.3 才成立，且"不累积"也才成立）。
⇒ **spec 必须显式写出"接触解算后把球心重投影到距该段 r"**（并把它写进 §4.3 的断言依据）；否则须改为**累积**误差界。

**（c）若确实累积，差多少。** 每次 ≤ ½·a·dt_sub² = **19.29 µm**（a=5）。N 次接触 ⇒ ≤ **N × 19.29 µm**：
- N=10 ⇒ 193 µm；N=100 ⇒ **1.93 mm**（≈ 球半径的 6.8%，且比 1e-5 m 判据高 **193 倍**）。
⇒ 这不是"Day 4 无影响（a=0）就没事"：spec 明说**式子在 Day 4 建好、Day 7 生效** ——
即这是一个**为 Day 7 埋下的静默失效率**（团队最忌的一类）。

### 缺陷 D3（中）**未覆盖的错误模式**（spec 的四列表没有格子）
1. **自由飞行位移无显式判据**：T1/T3 只验反射关系；T9 只验"可重复"；**没有一条断言 `p(t) = p₀ + v·t`**。
   ⇒ `remaining` 递减写错、子步循环漏一轮、用 `dt` 而非 `dt_sub` 等**只改变位移量**的 bug 无判据。
   （T10 只覆盖**垂直入射**的时间，属部分覆盖。）
   **建议**：加一条"自由飞行位移"测试：`a=0`，从 p₀ 以 v 走 N 步，断言 `|p − (p₀+v·N·dt)| ≤ 1e-6`。
2. **切向方向反转**（`v_t → −μ v_t`）：T1 只断言**模长** `|v_out·t̂| = μ|v_in·t̂|` ⇒ **模长不变、捕捉不到符号**。
   （T3 在 e=μ=1 下能抓到"绕法向反射"这一特例，但不是一般判据。）
   **建议**：T1 增一条**带符号**断言 `(v_out·t̂) = μ·(v_in·t̂)`（而非绝对值）。

### 缺陷 D5（中）T5b 负对照：**有效性未被 spec 钉死**
spec 只说 `DisableToiForDiagnosticsOnly` 关闭 TOI 后"子步末位做一次采样点检测"。

**建议**：spec 明确要求——**禁用模式必须复用生产路径的推进函数**，仅替换接触检测方式；否则 T5b 不计入判据 3。

## 五、§2.2 归纳闭合性（缺陷 D6，中-高）

spec 依赖的归纳不变量是"**球恒在库边内侧**"，据此 `n̂ = normalize(C−Q)` 自动就是内法向。
**该归纳在 Day 4 scope（不做袋口捕获）下不闭合。** 具体反例（我按真实数据算出，`_d4_recalc2.py`）：

```
起点 (0, 0)，速度 v = (0, −2) m/s        # 直指 side pocket[1]
pocket[1]: runtimeMouth A=(−0.107024, −0.635054)  B=(+0.107024, −0.635054)  口宽 214.048 mm
直库线 y = −0.635056，而 x ∈ (−0.107024, +0.107024) 区间【无任何段覆盖】= 袋口缺口
⇒ 球沿 x=0 前进，在 y=−0.635 处穿过缺口离开台面（该处无段 ⇒ 无任何阻拦）
距离 throatCenter(−0.0000, −0.695063) 最近 ≈ 9.31 mm < 触发半径 89.89 mm
⇒ PocketProximityEvents 必触发（§2.3 断言 == 0 ⇒ 该轨迹判为失败）
```

⇒ **结论**：归纳**不闭合**；设计上它**不是静默的**（计数器会记录，这是 §2.3 的正确之处），
但**它把"越界"定义为测试失败而非可处理情形** —— 因此
**T7（朝 82 段各中点与两端点各发一球）会朝袋口顶点发球**（如 `seg[20].a`、`seg[74].b` 正是袋口 mouth 顶点），
**与判据 9（`PocketProximityEvents == 0`）存在直接张力**。
**建议**：spec 明确 (a) T7 是否豁免判据 9；(b) 是否排除 12 个悬空端点；(c) 越界后球的处置（继续飞 / 冻结 / 终止测试）。
