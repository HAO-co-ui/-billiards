## 1. 缺障与修法

**缺陷（实测确认）**：`PoolSimulator.cs` 的球-球 TOI 扫描（主路径 `EarliestBallBallToi`）跳过条件只有
`if (!_active[i] && !_active[k])`，**未排除「离台冻结球」（`_frozen`）**；而 `ResolveDeepOverlaps`（深层重叠）与
`CollectSubstepEndContacts`（诊断）都有 `_frozen` 判据 ⇒ 三条球-球路径冻结处理不一致 = 漏写
（`CollectCandidatePairs` 本身不做任何过滤，过滤全部落在各调用点）。

**后果**：球越喉平面离台后冻结在喉平面外 1.05 mm，其碰撞圆盘（2r = 57.15 mm）向台内回伸 56.1 mm ⇒
**同一袋在结构上不可再被捕获**（后续来球在过喉平面前被弹回），且冻结球自身被写入速度、被位置修正推动。

**修法（一处判据 + 一处注释，不扩散）**：

```csharp
if (_frozen[i] || _frozen[k] || (!_active[i] && !_active[k]))
```

与诊断函数（`CollectSubstepEndContacts`）的既有判据**逐字一致**；注释把「在台上静止的球必须能被撞到」与
「离台冻结球一律不参与球-球解算」两种语义拆开，避免下一个人照旧注释再漏一次。

## 3. `T75` 采样余量加固

- **(d)** 直球段新增采样余量自检：`StepsSimulated × FDT − t ≥ 2e-3 s`（余量口径 = 撞后白球速度 × 该剩余时间）。
- **段 2（擦碰）**：白球 (0.12, 0) → 目标 (0.20, 0)，碰撞参数 `b = 2r − 1.6 mm`：
  - **(e)** `2r` 恒等式（擦碰下同样成立）；**(f)** 路径末点 == 幽灵球（逐位）；
  - **(g)** 擦碰语义自检：**目标球出射方向**沿接触瞬间连心线，`dot(out, u_in) < 0.5`（实测 0.2350 = cos 76.4°）；
  - **(h)** 擦碰段采样余量自检（实测 6.852e-3 s）。
- **⚠ 首版 (g) 的教训（已订正）**：曾用**白球**出射方向判「擦碰」，实测 dot = 0.9734 ⇒ 红。
  几何真相：碰撞参数是「到入射**射线**的垂距」，碰撞用的是**接触瞬间**的连心线角 θ_c ≈ 76°（不是 u 与初始
  连线的 44°）⇒ 白球几乎全速掠过（`v_after ≈ 0.97·v0`）、偏转仅 ~13.7°；而正碰下白球几乎停下但**方向不变** ——
  两者 dot 都接近 1，**无判别力**。擦碰与正碰的可靠区分量是**目标球**出射方向。

**实测自述（修复后全绿）**：
