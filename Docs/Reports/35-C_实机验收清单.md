## 1. 怎么用这张表

1. 按 **A → B → C → D** 的顺序做；每组做完把"结果"列填掉再进下一组。
2. "结果"只填三态之一：**通过** / **不通过** / **未测**。
   - **通过**：与"预期结果"**逐字对得上**（包括文案）。
   - **不通过**：有一点不符就记不通过，**并在备注写现象**（不要写"感觉不对"，写"显示了 X 而不是 Y"）。
   - **未测**：没做到 / 条件不具备（例如引导已经看过）。**未测不等于通过**。
3. **编号带"（观察）"的是观察项**：不通过请记录并报，但**不算阻断**。其余全部是**必过项**：
   **任一必过项不通过 ⇒ 这一版不算"能用"**，先修再谈其它。
4. **必过项里唯一可能因环境做不了的是 A2**（首次启动引导）：本机之前若已看过引导，记"未测"并在备注写"已看过"。带"（观察）"的 B5b / B12 / C16 属于"做不到也不阻断"。
5. 每条都能在打包后的 exe 里做。**不需要**开编辑器、不需要命令行、不需要看日志。
6. **请优先做 C2、C4、C15 这三条**：它们已被源码审计**预判为"很可能不通过"**（成因已定位到具体代码位置，engineering 侧待修）。实机若复现，**直接按 bug 报**，不要怀疑是自己操作错了；若这三条都正常通过，说明修复已进这一版。

**三条最容易被"感觉"糊过去的判定口径**（先看一遍再动手）：

- **"卡顿消失了"的判定不是"全程流畅"**，而是**"没有连续 2 秒以上画面完全不动"** + **"AI 思考时点台面能立刻有反应"**（见 C3）。
- **"AI 强度"不许要求 AI 必胜**。要看的是**同一档位内部的规律**（近台 / 远台 / 失误方式），以及**三档之间肉眼可分的强弱次序**（见 C7–C9）。
- **"球杆有没有材质"不看亮不亮，看有没有颜色**：洋红、纯白、纯黑、全透明都算不通过（见 D1）。

## 7. 已知限制（**不要当成 bug**）

1. **AI 每回合的候选数被预算限制。**
   参数表写的是 Club 32 / Expert 64 个候选，但**每回合累计计算预算只有 1500 ms**，
   运行期实际只会评到 **≈19–20 个候选**（这是按实测单候选 ≈74–78 ms **推出来的**，本清单要用 C7–C9 反推它是否成立）。
   ⇒ AI 在复杂台面上"想得不够全"是**设计内的取舍**，不是坏了。判断标准是 C7–C9 的**强弱次序与失误方式**，不是"AI 必须打进"。
2. **本包没有 PlayMode 自动化覆盖 —— 实机是唯一证据。**
   所有"手感 / 卡顿 / 材质"类结论**只能**由你这轮人工验收给出；自动化只覆盖了逻辑层。
   ⇒ 所以这张表**每一条都要真的做一遍**，不要用"之前测过"代替。
3. **AI 出杆前的"思考"可能比旧版略长。**
   旧版在一帧里把全部推演跑完 ⇒ 画面**卡死 2–4 秒**但出杆快；现在把计算摊到多帧 ⇒ **不卡，但等待时间可能比以前长一点**。
   这是**刻意换来的**：用"多等一两秒"换"不再冻结"。判 C3/C6 时按这个口径看。
4. **规划那一两秒画面可能不流畅（掉帧）。**
   每帧只做 1 次完整推演，而单次推演本身约 70–100 ms ⇒ AI 思考期间帧率会明显下降，看起来"一顿一顿"。
   ⇒ **判定"卡顿修好了"的标准是"没有 2 秒以上完全冻结 + 输入立刻有反馈"**（C3），**不是"全程 60 fps"**。
   若你看到的是"整体冻结、鼠标点下去几秒后才反应"，那才是 C3 不通过。
5. **AI 赢不等于 AI 有问题。** 三档都**刻意**保留了失误率（Expert 也有方向/力度误差）——"玩家赢一局"是预期结果，不是 bug。

## 8. 发现问题怎么报

按这三样写，别的都可以不写：

1. **哪一条编号**（例：`C4`、`B6`）；
2. **现象**（你看到什么 / 本该看到什么，逐字抄界面上的文字，例："状态行只有 `Ball in hand`，没有出现 `Opponent is shooting…`"）；
3. **能否稳定复现**：能复现就写最短步骤（例："AI 回合 → 左键点台面 → 连续 3 次都没提示"）；不能就用"偶发，约 10 次出现 2 次"。

可选补充（有就写，没有不影响受理）：**发生在哪个模式/难度**、**截图或录屏**、**发生的秒数**（C3/C6 尤其需要）、**有没有在作弊/调试状态下**（正常玩即可，不必改配置）。

填完后把"结果"列统计一下，一起回给主理人：
**必过项通过数 / 必过项总数**、**观察项不通过清单**、以及**任何一条 C3、C6 的秒数记录**（这两项的数字比"通过/不通过"更有用）。
